#+TITLE: org-babel-runbook demo: a tiny runbook on this machine and on itself over SSH
#+PROPERTY: header-args:bash :results output :async yes
#+PROPERTY: header-args:bash+ :var demo_dir="/tmp/obr-demo"
#+PROPERTY: header-args:bash+ :var demo_ver="1.0"

Everything here stays on this machine: the =local= session is a plain shell, the =remote= session is the same machine
reached over TRAMP (=/ssh:localhost:=, needs key login to localhost). Nothing is installed; files go to
=/tmp/obr-demo=. Steps 3 and 4 call =sudo true= (no changes) to show what the package fixes.

Load the package first ([[file:../README.md][README]]): =(require 'org-babel-runbook)= and =(org-babel-runbook-mode 1)=.

| Tag            | Meaning                                                         |
|----------------+-----------------------------------------------------------------|
| =:read_only:=  | changes nothing                                                 |
| =:rerun_ok:=   | a second run converges to the same state                        |
